# QRiff

A quick way to scan QR codes on your Linux desktop, without reaching for a phone.

- [Install from GitHub Releases](Installation)
- [Features and demo](https://github.com/Wattos/qriff#see-it-in-action)
- [Usage and desktop setup](https://github.com/Wattos/qriff/blob/master/docs/usage.md)
- [Report a bug](https://github.com/Wattos/qriff/issues)

Start with the AppImage or archive from a published release. Rust and a compiler
are only needed when building QRiff from source.
